Git Workflow Example

# 1. Create feature branch
git checkout -b feature/new-vpc

# 2. Make changes and test locally
terraform plan -out=plan.tfplan

# 3. Commit changes
git add .
git commit -m "Add new VPC configuration"

# 4. Push and create PR
git push origin feature/new-vpc

# 5. After PR merge
git checkout main
git pull origin main
terraform apply plan.tfplan

Remote State Management

S3 Backend with Locking

terraform {
  backend "s3" {
    bucket         = "team-terraform-state"
    key            = "environments/prod/terraform.tfstate"
    region         = "us-east-1"
    dynamodb_table = "terraform-locks"
    encrypt        = true
  }
}

State Sharing Between Teams

# Network team state
data "terraform_remote_state" "network" {
  backend = "s3"
  config = {
    bucket = "company-terraform"
    key    = "network/terraform.tfstate"
    region = "us-east-1"
  }
}

# Use network outputs
resource "aws_instance" "app" {
  subnet_id = data.terraform_remote_state.network.outputs.private_subnets[0]
}

State Security

  • • Enable encryption at rest
  • • Use IAM roles with least privilege
  • • Enable versioning on state buckets
  • • Use separate state files per environment

CI/CD Pipeline Integration

Automated Infrastructure Deployment

Implement GitOps workflows with automated testing, security scanning, and deployment.

GitHub Actions Workflow

name: 'Terraform CI/CD'
on:
  push:
    branches: [ main ]
  pull_request:
    branches: [ main ]

jobs:
  terraform:
    name: 'Terraform'
    runs-on: ubuntu-latest
    
    steps:
      - name: Checkout
        uses: actions/checkout@v3
        
      - name: Setup Terraform
        uses: hashicorp/setup-terraform@v2
        
      - name: Terraform Format
        run: terraform fmt -check
        
      - name: Terraform Init
        run: terraform init
        
      - name: Terraform Validate
        run: terraform validate
        
      - name: Terraform Plan
        run: terraform plan -out=plan.tfplan
        
      - name: Terraform Apply
        if: github.ref == 'refs/heads/main'
        run: terraform apply -auto-approve plan.tfplan

Collaboration Best Practices

✅ Do These

  • Use remote state with locking
  • Implement code review process
  • Use consistent naming conventions
  • Document infrastructure changes
  • Test changes in non-prod first

❌ Avoid These

  • Don't use local state in teams
  • Avoid manual infrastructure changes
  • Don't skip security scanning
  • Avoid long-running feature branches
  • Don't ignore cost estimation
