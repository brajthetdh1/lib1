Getting Started with Terraform

Learn the fundamentals of Terraform to start managing your infrastructure as code.

Introduction to Terraform

Terraform is an infrastructure as code (IaC) tool that allows you to build, change, and version infrastructure safely and efficiently.

Note: This guide assumes you have basic knowledge of cloud computing concepts.

Declarative

Describe your desired infrastructure state

Cloud Agnostic

Works with AWS, Azure, GCP and more

Versioning

Track and manage infrastructure changes

Installation

Install on macOS with Homebrew

brew tap hashicorp/tap
brew install hashicorp/tap/terraform

Install on Windows with Chocolatey

choco install terraform

Install on Linux

# Download the package
wget https://releases.hashicorp.com/terraform/1.5.0/terraform_1.5.0_linux_amd64.zip

# Install unzip if needed
sudo apt-get install unzip

# Unzip and install
unzip terraform_1.5.0_linux_amd64.zip
sudo mv terraform /usr/local/bin/

Tip: Verify your installation by running terraform version in your terminal.

Basic Concepts

Providers

Providers are plugins that Terraform uses to interact with cloud providers, SaaS providers, and other APIs.

terraform {
  required_providers {
    aws = {
      source = "hashicorp/aws"
      version = "~> 4.0"
    }
  }
}

provider "aws" {
  region = "us-west-2"
}

Resources

Resources are the most important element in the Terraform language. Each resource block describes one or more infrastructure objects.

resource "aws_instance" "web" {
  ami           = "ami-0c02fb55956c7d316"
  instance_type = "t3.micro"

  tags = {
    Name = "HelloWorld"
  }
}

Variables

Input variables serve as parameters for a Terraform module, allowing aspects of the module to be customized.

variable "instance_type" {
  description = "The type of EC2 instance to launch"
  type        = string
  default     = "t3.micro"
}

resource "aws_instance" "example" {
  ami           = "ami-0c02fb55956c7d316"
  instance_type = var.instance_type
}

Your First Configuration

Step-by-Step Guide

1

Create a directory

Create a new directory for your Terraform configuration

mkdir terraform-demo
cd terraform-demo
2

Create main.tf

Create a file named main.tf with the following content:

# Configure the AWS Provider
provider "aws" {
  region = "us-east-1"
}

# Create a VPC
resource "aws_vpc" "main" {
  cidr_block = "10.0.0.0/16"
  
  tags = {
    Name = "Main VPC"
  }
}
3

Initialize Terraform

Run terraform init to initialize your working directory

terraform init
4

Plan the infrastructure

Run terraform plan to see what Terraform will create

terraform plan
5

Apply the configuration

Run terraform apply to create the infrastructure

terraform apply
